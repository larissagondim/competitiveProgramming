## Repository structure

- `C/`: solutions written in C.
- `C++/`: solutions written in C++.
- `python/`: solutions written in Python.
- Within each language directory, solutions are grouped by topic: `Beginner`, `Mathematics`, `Strings`, and `AD-HOC` where applicable.

## How to run

The solutions have no external dependencies or specific build system.

### C

```bash
gcc -std=c11 -O2 -Wall C/Beginner/1000.c -o 1000
./1000 < input.txt
```

Replace the source path and output name with the desired solution.

### C++

```bash
g++ -std=c++17 -O2 -Wall C++/Beginner/1001.cpp -o 1001
./1001 < input.txt
```

Replace the source path and output name with the desired solution.

### Python

```bash
python3 python/Beginner/1145.py < input.txt
```

Each program reads from standard input and writes to standard output according to the corresponding problem statement.
